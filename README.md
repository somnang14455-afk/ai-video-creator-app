# AI Video Creator

Android application for AI-assisted video production.

## Planned features
- AI Drama Editor
- Music Video Editor
- Advertisement Video Editor
- Video cutting and merging
- Audio, music, subtitles, and overlays
- Social-media aspect ratios
- Preview, thumbnail, title, and hashtags
- Export and publishing workflow

## Project layout
- app/: Android app interface
- backend/: Python processing and service logic
- assets/: images, icons, and media assets
- docs/: architecture and build notes

## Security
Do not commit API keys, bot tokens, passwords, or .env files.
